# Security Policy

## Supported versions

The latest released 1.x version receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through
GitHub Security Advisories ("Security" tab → "Report a vulnerability") on
https://github.com/piashcse/zodkmp.

You can expect an acknowledgement within 72 hours. Please include a minimal reproduction,
affected targets, and the impact you believe the issue has.
